# Building-function modelling and spatial analysis

Code for multimodal building-function classification, BFMI calculation and spatial econometric analysis.

- [BHENet](bhenet-model/): model architecture, HDF5 data loading, training and inference.
- [Spatial analysis](spatial-analysis/): 12-class BFMI calculation and spatial Durbin regression with spatial error.

Each directory contains its installation and usage instructions.
